Running AI on Your Own Device: Muse Spark Open and Realistic Options for Creators

Updated 16 October 2026 · by AutomateWithAI

Quick answer: Meta released Muse Spark Open on 15 October 2026: an open-weight model with 816B total parameters (42B active) and a 1M-token context window. Meta says it runs on a desktop using two Apple M5 Ultra Mac Studios, which is very high-end hardware. Most creators can try it through hosted API platforms instead, or run smaller models locally with free tools like Ollama.

What is Muse Spark Open?

According to Meta's announcement (15 October 2026), Muse Spark Open is a natively multimodal, open-weight model with 816B total parameters, 42B of them active, and a 1M-token context window. Meta built it for coding and agentic work. The weights are released under the Muse Model License, which has limited commercial terms.

Can I really run it at home?

Technically yes, but not on a normal laptop. Meta says it is the first model in its class to run on a desktop using two Apple M5 Ultra Mac Studios with Apple's MLX framework. Each Mac Studio's GPU can use up to 512 GB of unified memory, so two together hold the whole model, about a terabyte. That is a very expensive setup, far beyond what most creators own.

How can creators try it without that hardware?

Meta lists hosted API platforms: Baseten, Fireworks AI, Groq, Modal, Nebius, OpenRouter and Together AI. The weights are also on Hugging Face, Amazon SageMaker AI, Google Cloud Model Garden and Microsoft Foundry Models. Hosted platforms usually charge per use, so check each one's pricing.

Meta's own creator-relevant demo: running on-device, the model drove DaVinci Resolve end to end, reviewing footage frame by frame to find the strongest moments and crop them vertically.

What are realistic on-device AI options for creators?

  • Ollama (free, open source) runs smaller AI models locally on macOS, Windows and Linux. For example, ollama run gemma4 downloads and chats with Google's Gemma 4. Good for drafting captions, hooks and scripts offline. How fast it runs depends on your computer's memory and graphics.
  • Local voiceovers: see our guide to VoiceStudio, a free local ElevenLabs alternative, which also runs on the CPU without a dedicated GPU, just more slowly.

Why run AI locally at all?

Local tools keep your drafts and recordings on your own computer, work offline, and have no per-message limits. The trade-off is that smaller local models are usually less capable than the biggest cloud models, and big models need serious hardware.
