Free ChatGPT Prompts for Instagram Reel Scripts and Hooks

Updated 16 October 2026 · by AutomateWithAI

Quick answer: Give ChatGPT your niche, audience and one real takeaway, ask for several short hooks (6–10 words), then a 20–30 second script with on-screen text, and finally a loop-friendly ending. The prompts below work on ChatGPT's free tier. Always edit the result into your own words and check every fact before you film.

How should I use these prompts?

Replace the [BRACKETS] with your details. Ask for several options, pick the best, and rewrite it so it sounds like you. Free ChatGPT has usage limits set by OpenAI, and AI can state wrong facts confidently, so verify anything you show on screen.

Prompt 1: 20 hooks

Use this when you know the topic but need an opening line.

You write hooks for short Instagram reels about [NICHE] for [WHO]. Topic: [TOPIC]. The one real takeaway: [TAKEAWAY]. Write 20 hooks, 6-10 words each, in 4 styles: question, surprising fact, mistake to avoid, "watch this". No clickbait the video can't deliver, no income claims.

Prompt 2: a 25-second script

Turns your best hook into a script you can record over real screen footage.

Write a 25-second voiceover script (about 65 words) for a vertical reel. Hook: [HOOK] Steps I will show on screen: [STEP 1], [STEP 2], [STEP 3] Format: hook line, 3 short steps, one-line result, one-line call to action ("Save this for later"). Plain words, short sentences, no hype.

Prompt 3: on-screen text and shot list

For a fast-cut edit, like the notification-banner hook style.

Split this script into shots of about 0.5-1.5 seconds. For each shot give: what is on screen (real app screen I recorded), on-screen text (max 6 words), and the matching voiceover words. Script: [PASTE SCRIPT]

Prompt 4: a loop-friendly ending

A reel that ends where it starts invites a second watch.

Rewrite the last line of this script so it flows naturally back into the first line when the video loops. First line: [HOOK] Script: [PASTE SCRIPT] Give 3 options.

Prompt 5: script checker

Catches weak spots before you film.

Review this reel script as a strict editor. 1) Does the first line make someone stop scrolling? Suggest a stronger version. 2) Cut any word that isn't needed. 3) Flag any claim that might be false or exaggerated. Script: [PASTE SCRIPT]

Frequently asked questions

Can I use free ChatGPT to write Instagram reel scripts?

Yes. The free tier handles hooks, short scripts and shot lists. Free users have usage limits set by OpenAI, and you should edit and fact-check every script.

How long should a reel script be?

For a 20–30 second reel, roughly 50–80 spoken words. Read it aloud and time it before recording.

What makes a good reel hook?

A short line, around 6–10 words, that promises something the video actually delivers, such as a question, a surprising fact or a mistake to avoid.

Should I post ChatGPT scripts as they are?

No. Rewrite them in your own voice, remove anything you can't back up, and check facts before filming.
