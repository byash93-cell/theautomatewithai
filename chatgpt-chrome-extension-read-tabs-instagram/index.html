How to Use ChatGPT's Chrome Tab Feature for Instagram Content

Updated 16 October 2026 · by AutomateWithAI

Quick answer: With OpenAI's ChatGPT extension installed in Google Chrome, you can tag Chrome in ChatGPT's web or desktop app and it can use the tabs you have open. For example, it can compare products across tabs, put details into a comparison sheet with source links, or fill out a form and stop before submitting. The Verge reported the update on 15 October 2026.

What changed in ChatGPT's Chrome extension?

According to The Verge (15 October 2026), ChatGPT can now view your browser tabs when you tag Chrome in ChatGPT's web or desktop app, as long as the ChatGPT Chrome extension is installed. OpenAI's demo showed someone asking ChatGPT to compare three open tabs of sofas.

The sidebar was also updated so you can use ChatGPT, including your conversation history, without leaving the page. ChatGPT Work can also "control" Chrome tabs for tasks like sending messages, filling out forms, downloading files and grouping tabs.

What example tasks did OpenAI give?

  • Fill out a registration form from an event brief, and stop before submitting.
  • Put the vendors in your open tabs into a comparison sheet, with pricing, key features and source links.
  • Compare contractor services across tabs, then draft an email to the best fit.
  • Fill out an open form and add an appointment to your calendars.

How can Instagram creators use it?

  1. Trend research: open 3–5 news articles or posts about a trend, tag Chrome and ask for a summary of what's new, with source links, to script a reel from.
  2. Tool comparison reels: open the pricing pages of 3 tools and ask for a table of free-plan limits. Always check the numbers on the pages yourself before posting.
  3. Caption drafts: with a product or tutorial page open, ask the sidebar for 5 hook ideas based on that page.
  4. Collab outreach: compare brand pages in your tabs, then ask for a short, personal draft email. Read and edit it before you send anything.

How do I set it up?

  1. Install (or update) OpenAI's ChatGPT extension from the Chrome Web Store.
  2. Open the tabs you want ChatGPT to work with.
  3. In ChatGPT's web or desktop app, tag Chrome in your message and say what you want, for example "compare these tabs in a table with price and key features".

Availability and exact steps may vary by account and region. Check OpenAI's help pages for the latest details.

What should I be careful about?

Only open tabs you're comfortable sharing with ChatGPT, since it can read what's in them. For forms, ask it to stop before submitting, and review everything yourself. AI summaries can be wrong, so verify facts and prices before you put them in a reel.
